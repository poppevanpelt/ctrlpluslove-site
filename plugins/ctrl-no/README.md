# ctrl+no™

A pressure-resistant decision check from [ctrl+love](https://www.ctrlpluslove.com).

Most technology helps people do things. ctrl+no helps decide which things should **not be done yet**.

## Try it

Ask Claude:
- “Should I pay this?”
- “They want me to sign this today. Do I have to?”
- “This feels wrong. Run ctrl+no.”
- “Can I say no to this request?”

ctrl+no runs three checks:
1. Do I have to?
2. Do I have to now?
3. What do I say?

It then proposes the smallest reversible move and a ready-to-send response.

## Status

**v0.1.0 — skill-first plugin.**

The decision behavior is deliberately being validated before we add an interactive MCP App. That keeps the first version small enough to fail usefully.

## Privacy

This version has no remote MCP server and sends no plugin-owned telemetry. It works only with information the user provides to Claude.
